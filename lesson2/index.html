[2차시] 사물 인터넷과 사회 변화

📜 사물인터넷(IoT) 발전의 역사

1. 태동기: 아이디어의 시작 (1980년대 ~ 1990년대 초)

  • 최초의 IoT 기기(1982년): 카네기 멜런 대학교의 코카콜라 자판기. 학생들이 자판기에 센서를 달아 멀리서도 콜라의 재고와 온도(시원함 정도)를 네트워크로 확인한 것이 시초임.
  • 최초의 인터넷 연결 가전(1990년): 존 롬키(John Romkey)가 만든 인터넷 연결 토스터기. TCP/IP 프로토콜을 이용해 컴퓨터로 전원을 제어함.

2. 명명기: '사물인터넷' 용어의 탄생 (1990년대 말)

  • 용어 정립(1999년): P&G에서 근무하던 케빈 애쉬턴(Kevin Ashton)이 RFID(무선 식별) 기술을 공급망 관리에 도입하면서 'Internet of Things'라는 용어를 처음 제안함.
  • RFID의 발전: 사물에 식별 번호를 부여하고 이를 네트워크로 관리하려는 시도가 본격화됨.

3. 확산기: 대중화와 기술의 융합 (2000년대 ~ 2010년대 초)

  • 인터넷 냉장고(2000년): LG전자가 세계 최초로 인터넷 연결 냉장고를 출시하며 '스마트 홈'의 개념을 제시함.
  • 장치 수의 역전(2008~2009년): 전 세계 인터넷에 연결된 사물(기기)의 수가 전 세계 인구수를 추월하며 본격적인 IoT 시대가 열림.
  • IPv6 도입(2011년): 폭발적으로 늘어나는 기기들에 IP 주소를 부여하기 위해 무한대에 가까운 주소를 제공하는 IPv6 체계가 본격적으로 확산됨.

4. 가속기: AI와 데이터의 결합 (2010년대 중반 ~ 현재)

  • 플랫폼 경쟁: 구글(Nest 인수), 애플(HomeKit), 삼성(SmartThings) 등 거대 IT 기업들이 IoT 생태계를 구축함.
  • IIoT와 AIoT: 제조 현장의 산업용 사물인터넷(IIoT)과 인공지능이 결합한 사물지능(AIoT)으로 발전하여 자율주행, 스마트 시티 등으로 확장 중임.

📜 사물인터넷(IoT) 3대 핵심 요소

핵심 요소주요 역할구체적인 예시
1. 센서 및 디바이스
(Sensors & Devices)		주변 환경의 데이터를 수집하고 물리적인 동작을 수행하는 '오감' 역할온도·습도 센서, GPS, 가속도 센서, 스마트 도어락, 웨어러블 기기
2. 네트워크
(Connectivity)		수집된 데이터를 클라우드나 서버로 전달하는 '신경계' 역할Wi-Fi, 블루투스(Bluetooth), 5G/LTE, Zigbee, NFC
3. 서비스/인터페이스
(Intelligence/Service)		데이터를 분석하여 최적의 판단을 내리고 사용자에게 가치를 제공하는 '두뇌' 역할스마트폰 앱 알림, 인공지능(AI) 분석, 자동 온도 조절 시스템, 빅데이터 시각화

🚀 자율주행차(IoT) 기반 탐구 주제

1. 에지 컴퓨팅(Edge Computing)과 실시간 데이터 처리의 최적화

  • 탐구 동기: 자율주행차는 초당 수 기가바이트(GB)의 데이터를 생성함. 이를 모두 클라우드로 보내 처리하면 통신 지연(Latency)으로 인해 사고가 발생할 수 있음.
  • 조사 내용: 차량 내부(Edge)에서 즉시 처리해야 할 데이터와 클라우드로 보내 학습시켜야 할 데이터를 구분하는 기준과 알고리즘 조사함.
  • IoT 관점: 중앙 집중형 네트워크의 한계를 극복하는 분산 거점형 처리 방식의 효율성 분석함.
단계역할위치주요 작업

엣지 (Edge)실시간 분석현장 서버, 게이트웨이즉각적인 반응(정지 명령 등), 데이터 필터링
클라우드 (Cloud)장기 저장 및 학습원격 데이터 센터빅데이터 분석, AI 모델 업데이트, 전체 관리

자율주행 자동차의 경우

구분발생 위치주요 비유핵심 판단 내용
인-비히클 엣지차량 본체"운전자의 본능"급제동, 조향, 물체 인식
네트워크 엣지기지국 / 노변 장치"교통경찰 / 내비"신호 정보, 사각지대 위험 알림
클라우드중앙 데이터 센터"지도 제작소"고정밀 지도 업데이트, AI 학습

2. V2X(Vehicle-to-Everything)를 활용한 스마트 시티 교통 제어

  • 탐구 동기: 자율주행차가 도로의 모든 사물(신호등, 다른 차량, 보행자)과 통신(IoT)한다면 교통 체증과 사고를 획기적으로 줄일 수 있음.
  • 조사 내용: V2V(차량 간), V2I(차량-인프라 간) 통신 표준을 조사하고, 신호등 없는 교차로에서 차량들이 서로 통신하여 순서대로 통과하는 시뮬레이션 원리 탐구함.
  • IoT 관점: 개별 사물이 군집 지능(Swarm Intelligence)을 형성하여 시스템 전체의 효율을 높이는 과정 고찰함.

3. 소프트웨어 중심 자동차(SDV)의 보안과 무선 업데이트(OTA)

  • 탐구 동기: IoT 기기의 최대 취약점은 해킹임. 주행 중인 자동차의 제어권이 탈취될 경우 치명적인 결과를 초래함.
  • 조사 내용: 테슬라와 같은 기업이 사용하는 OTA(Over-the-Air) 기술의 보안 프로토콜과 소프트웨어 업데이트를 통한 성능 개선 사례 조사함.
  • IoT 관점: 연결성이 강화될수록 중요해지는 사이버 보안 위협과 '안전한 연결'을 위한 암호화 기술(블록체인, 인증서 등) 탐구함.

🛡️ IoT와 DDoS 공격: 탐구 주제 추천

1. 미라이(Mirai) 넷 사례를 통해 본 IoT 보안 취약점 분석

  • 탐구 내용: 2016년 전 세계 인터넷을 마비시켰던 '미라이 보트넷' 사건을 중심으로, 초기 설정 비밀번호(admin/1234 등)가 어떻게 대규모 공격의 단초가 되었는지 조사함.
  • 핵심 포인트: IoT 기기들이 PC에 비해 보안 업데이트가 어렵고 연산 능력이 낮아 방어 체계가 부실하다는 '비대칭적 취약성'을 분석함.

2. IoT 기기의 '좀비화' 방지를 위한 가역적 보안 메커니즘 설계

  • 탐구 내용: 사용자가 기기 보안을 관리하기 어려운 환경에서, 제조사 단계의 보안 강화 대책(기기별 고유 비밀번호 부여, 펌웨어 자동 업데이트 등)의 실효성을 탐구함.
  • 핵심 포인트: '시큐어 부트(Secure Boot)'나 '하드웨어 기반 보안(TrustZone)' 기술이 어떻게 IoT 기기의 변조를 막는지 공학적으로 접근함.

3. 트래픽 패턴 분석을 통한 IoT 기반 DDoS 공격 탐지 알고리즘

  • 탐구 내용: 정상적인 IoT 데이터 흐름과 공격 시 발생하는 비정상적 트래픽의 패턴 차이를 연구함. 인공지능(AI)을 활용하여 이상 징후를 조기에 발견하는 기술적 대책을 모색함.
  • 핵심 포인트: 네트워크 게이트웨이(공유기 등)에서 특정 기기의 트래픽이 급증할 때 이를 자동으로 차단하는 '침입 방지 시스템(IPS)'의 원리를 실험함.

사물 인터넷 시스템 구현

단계주요 내용 및 아이디어 전개관련 요소 (IoT 3대 요소 적용)
1. 문제 발견학생마다 원하는 배식량이 다르지만 매번 말하기 번거롭고, 잔반이 발생하는 문제 인식사용자 요구사항 분석
2. 데이터 수집잔반 처리기에 설치된 카메라를 통해 개별 학생이 남기는 음식의 종류와 양을 기록센서 및 디바이스 (카메라/센서)
3. 데이터 분석수집된 지난 50일간의 데이터를 분석하여 학생별 식사 패턴 및 선호도 파악지능형 서비스 (빅데이터/AI)
4. 사물 인식배식대에 선 학생(김OO, 박OO)을 얼굴 인식이나 태그 등으로 식별네트워크 및 인터페이스
5. 맞춤형 실행분석된 데이터를 바탕으로 로봇이 학생별 최적의 양(예: 쌀밥 300g, 국 최소 배식)을 자동으로 배부지능형 서비스 (자동 제어)

🔄 시스템 작동 순서도 (Flowchart)

  1. [문제 정의] 급식 잔반 발생 및 개인별 맞춤 배식의 어려움
  1. [데이터 축적] 잔반 처리기(센서)를 통해 50일간 학생별 식습관 데이터 수집
  1. [대상 식별] 배식 로봇이 앞에 선 학생을 인식
  1. [데이터 매칭] 클라우드/서버에 저장된 해당 학생의 선호도 데이터 호출
  1. [자동 배식] 분석된 선호량에 맞춰 로봇 팔이 음식 배부
  1. [피드백] 식사 후 잔반 데이터를 다시 수집하여 분석 모델 업데이트 (반복)

🔄 바이브 코딩의 순서도

단계별 내용 (AI에게 던질 질문들)

1단계: 시뮬레이션 환경 만들기

학생 데이터를 분석하는 대시보드부터 만들기

AI 프롬프트 예시: "학생별 50일간의 식사 데이터(남긴 양, 선호 음식)를 시뮬레이션하는 Python 프로그램을 만들어줘. 김OO 학생은 밥 300g을 선호하고, 박OO 학생은 국을 싫어한다는 설정이야."

2단계: 학생 인식 로직 추가 (이미지 기반)

만화 속 로봇이 눈(카메라)으로 학생을 알아보는 기능을 가상으로 구현함.

AI 프롬프트 예시: "OpenCV 라이브러리를 사용해서 웹캠으로 사람 얼굴을 인식하면, 해당 학생의 이름을 화면에 띄우고 그 학생의 선호 배식량을 보여주는 코드를 작성해줘."

3단계: 엣지 컴퓨팅 구조 설계

속도를 위해 '현장'에서 처리하는 논리를 넣음.

AI 프롬프트 예시: "서버에 접속하지 않고 로컬 기기(엣지)에서 즉시 학생을 식별하고 배식량을 결정하는 구조로 코드를 최적화해줘. 반응 속도가 0.5초 이내여야 해."
