객체(Object)란?

1. 함수 vs 클래스

구분함수 (Function)클래스 (Class)
정의특정 작업을 수행하는 코드 뭉치객체를 만들기 위한 설계도 (데이터+함수)
핵심 키워드defclass
접근 방식호출 시 즉시 실행인스턴스(객체)를 생성한 후 사용
상태 유지호출이 끝나면 로컬 변수 소멸객체 내부에 데이터(변수) 저장 및 유지
비유레시피 (조리 과정 그 자체)붕어빵 틀 (틀과 그 안의 팥/슈크림 정보)

함수 (Function): "무엇을 하는가?"

함수는 특정 작업을 수행하는 코드의 집합이며, 데이터를 입력받아 처리하고 결과를 반환하는 동작에 집중함.

  • 목적: 코드의 중복을 줄이고 특정 로직을 재사용하기 위함
  • 특징: 한 번 실행되고 나면 내부의 상태(변수 등)를 유지하지 않고 사라짐.
  • 키워드: def
def greet(name):
    return f'안녕하세요, {name}님!'

print(greet('철수'))

클래스 (Class): "무엇인가?" (상태 + 동작)

클래스는 데이터(상태)와 그 데이터를 다루는 함수(동작)를 하나로 묶은 틀로, 이 틀을 통해 만들어진 실체를 인스턴스(객체)라고 함.

  • 목적: 관련된 변수와 함수를 하나로 묶어 복잡한 시스템을 구조화하기 위함임.
  • 특징: 객체마다 고유한 데이터를 유지할 수 있음.
  • 키워드: class
class Dog:
    def __init__(self, name):
        self.name = name 

    def bark(self):      
        return f'{self.name}가 멍멍! 하고 짖습니다.'

my_dog = Dog('초코')

print(my_dog.bark())

2. 클래스(Class)

클래스의 구조

class FishBread:
    def __init__(self, f, b):
        self.flour = f
        self.bean = b

    def makeFishBread(self):
        print(f'{self.flour}과 {self.bean}으로 만든 붕어빵 제조!')

my_bread = FishBread('중력분', '단팥')

my_bread.makeFishBread()
요소코드 내용의미
속성 (Variable)self.flour, self.bean이 붕어빵이 가진 상태 (재료 정보)
메서드 (Method)makeFishBread(self)이 붕어빵이 할 수 있는 동작 (제조 결과 출력)
생성자 (__init__)def __init__(self, f, b):붕어빵이 처음 만들어질 때 재료를 넣어주는 준비 단계

클래스의 선언, 속성, 기능

class Calculator:
    def __init__(self, n1, n2):
        self.num1 = n1
        self.num2 = n2

    def add(self):
        print(f'더하기: {self.num1 + self.num2}')

    def sub(self):
        print(f'빼기: {self.num1 - self.num2}')

    def mul(self):
        print(f'곱하기: {self.num1 * self.num2}')

    def div(self):
        if self.num2 != 0:
            print(f'나누기: {self.num1 / self.num2}')
        else:
            print('0으로 나눌 수 없습니다!')

print('--- 초간단 계산기 ---')

val1 = float(input('첫 번째 숫자: '))
val2 = float(input('두 번째 숫자: '))

calc = Calculator(val1, val2)

print('\n[ 결과 ]')
calc.add()
calc.sub()
calc.mul()
calc.div()
코드역할용어
class Calculator계산기가 가져야 할 규칙 정의클래스 (Class)
calc실제로 동작하는 계산기 한 대인스턴스 (Instance)
calc.add()인스턴스가 가진 기능을 실행메서드 호출 (Method Call)

__init__(self, 매개변수) 형태를 취하게 된 유래?

  • 매직 메서드(Magic Method) 또는 던더(Dunder - Double Under) 메서드라고 부름.
  • 언어 자체와의 약속: 파이썬 설계자 귀도 반 로섬(Guido van Rossum)은 사용자가 만든 일반 메서드 이름과 시스템 메서드 이름이 충돌하지 않기를 원함.
  • 유래: 명시적으로 __를 붙여 "이것은 파이썬 엔진이 특정 시점(객체 생성 등)에 자동으로 호출하는 특수 기능이다"라는 것을 명확히 표시한 것임.
  • Smalltalk의 영향: 파이썬은 최초의 객체 지향 언어인 Smalltalk의 영향을 받음. Smalltalk에서는 객체를 초기화할 때 init이나 initialize라는 명칭을 사용함.
  • Modula-3의 영향: 귀도는 파이썬을 설계할 때 Modula-3라는 언어의 인터페이스 방식을 참고함. Modula-3에서는 메서드의 첫 번째 인자로 해당 객체 자신을 명시적으로 전달했고, 이것이 파이썬의 self로 이어짐.
요소의미유래/이유
__...__매직 메서드사용자 정의 이름과의 충돌 방지 및 인터프리터용 예약 함수 표시
init초기화Smalltalk 등 초기 객체지향 언어의 관례 (Initialization)
self인스턴스 자신Modula-3의 영향 및 '명시적인 것이 낫다'는 파이썬의 철학
