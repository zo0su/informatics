코드 라인설명
import csvCSV 파일을 다루기 위한 파이썬 내장 모듈을 불러오기
f = open('seoul.csv')seoul.csv 파일을 읽기 모드로 열기. 변수 f는 파일 객체를 가리킴.
data = csv.reader(f)열린 파일 f를 CSV 형식으로 읽어 들임. data는 파일의 내용을 한 줄씩 넘겨주는 반복 가능(iterable) 객체가 됨.
for row in data :나머지 데이터(본문)를 한 줄씩 가져와서 row라는 변수에 담아 반복함.
print(row)읽어온 줄(row)을 출력함. 이때 각 줄은 리스트(List) 형태로 출력됨.
f.close()파일 읽기가 끝났으므로 열려 있는 파일 객체를 닫아 메모리 자원을 해제함.
import csv
f = open('seoul.csv', encoding='cp949')
data = csv.reader(f)
header = next(data)
max_temp = -999
max_date = ''
for row in data:
    if row[-1] == '' :
        row[-1] = -999
    row[-1] = float(row[-1])
    if max_temp < row[-1]:
        max_date = row[0]
        max_temp = row[-1]
f.close()
print(f'기상 관측 이래 서울의 최고 기온이 가장 높았던 날은 {max_date}로, {max_temp}도였습니다.')
단계주요 코드명사 종결형 설명
1. 파일 로드open('seoul.csv', encoding='cp949')cp949 인코딩을 적용하여 한글 깨짐 없이 CSV 파일 오픈
2. 객체 생성csv.reader(f)파일 내용을 줄 단위로 읽어올 수 있는 reader 객체 생성
3. 헤더 스킵header = next(data)최상단 제목 줄(날짜, 지점 등)을 건너뛰고 실제 데이터로 이동
4. 변수 초기화max_temp = -999최고 기온 비교를 위한 기준값 설정 (아주 낮은 숫자로 시작)
5. 결측치 판별if row[-1] == '' :기온 값이 비어 있는 행(결측치)을 찾아 에러 발생 방지
6. 임시값 할당row[-1] = -999데이터가 없는 경우 비교 대상에서 제외되도록 아주 낮은 값 대입
7. 데이터 변환float(row[-1])문자열 타입의 기온 데이터를 연산 가능한 실수형으로 변환
8. 조건 비교if max_temp < row[-1] :현재 줄의 기온이 기존 기록보다 높을 경우 조건문 진입
9. 기록 갱신max_date = row[0], max_temp = row[-1]새로운 최고 기온과 해당 날짜를 변수에 덮어쓰기
10. 파일 폐쇄f.close()파일 사용 완료 후 시스템 자원 반납 및 연결 종료
11. 결과 발표print(...)최종적으로 저장된 최고 기온 발생일과 온도 출력

UTF-8과 CP949는 컴퓨터가 문자를 숫자로 변환(인코딩)하는 방식의 차이가 있음.

1. UTF-8 (Universal Coded Character Set + Transformation Format – 8-bit)

현재 전 세계적으로 가장 많이 쓰이는 표준 인코딩 방식임.

  • 특징: 가변 길이 인코딩을 사용함. 영어는 1바이트, 한글은 3바이트로 저장함.
  • 장점: 전 세계 모든 언어(한글, 한자, 이모지 등)를 하나의 규칙으로 다 표현할 수 있음. 웹사이트나 최신 소프트웨어의 기본값임.
  • 단점: 한글 한 글자를 저장할 때 CP949보다 용량을 조금 더 차지함.

2. CP949 (Code Page 949)

마이크로소프트(MS)가 한글 윈도우에서 사용하기 위해 만든 방식으로, 'MS949'라고도 부름.

  • 특징: 고정된 2바이트 체계임. 영어는 1바이트, 한글은 2바이트로 저장함.
  • 장점: 옛날 윈도우 환경이나 엑셀(Excel) 구버전과의 호환성이 좋음. 한글 저장 시 용량이 UTF-8보다 작음.
  • 단점: 한국어 외에 다른 나라 언어를 동시에 표현하는 데 한계가 있음. 표준이 아니기에 다른 운영체제(Mac, Linux)에서 파일이 깨지는 원인이 됨.

1~5행: 데이터 로드 및 전처리

  • 1~2행: CSV 파일 처리를 위한 csv 및 그래프 시각화를 위한 matplotlib.pyplot 모듈 임포트.
  • 3행: 한글 인코딩(cp949) 규칙을 적용하여 busan.csv 파일 오픈.
  • 4행: 열린 파일을 콤마 기준으로 읽어오는 reader 객체 생성.
  • 5행: 데이터의 첫 번째 줄(속성명)을 건너뛰기 위한 next() 함수 실행.

6~8행: 데이터 저장 리스트 초기화

  • 6~8행: 연도별 최고 기온(high)과 최저 기온(low)을 담기 위한 빈 리스트 생성.

9~15행: 조건별 데이터 추출 및 변환

  • 9행: 전체 데이터를 한 줄씩 확인하는 반복문 수행.
  • 10행: 최고 기온(row[-1])과 최저 기온(row[-2]) 데이터의 결측치 존재 여부 확인.
  • 11행: 날짜 문자열을 하이픈() 기준으로 분리하여 리스트로 치환.
  • 12행: 데이터의 연도가 2009년 이후인지 여부 판단. 2009 <= int(row[0].split('-')[0])라고 작성된 부분은 수학적으로 해석하면 "2009이 데이터의 연도보다 작거나 같다"는 뜻임. 이를 우리가 흔히 쓰는 문장으로 뒤집어 보면 "데이터의 연도가 2009보다 크거나 같다"가 됨. 즉, 2009년을 포함하여 그 이후의 모든 연도를 선택하겠다는 의도임.
  • 13행: 월과 일이 각각 '05'와 '29'에 해당하는지(생일 여부) 비교.
  • 14~15행: 조건에 부합하는 최고/최저 기온을 실수형으로 변환하여 리스트에 각각 추가.
