Microsoft Power BI란?

📊 Power BI의 장점

  • 코딩이 필요 없다 (No-Code): 파이썬 같은 프로그래밍 언어를 몰라도 마우스 클릭만으로 전문가 수준의 대시보드를 만들 수 있음.
  • 강력한 시각화: 단순히 그래프를 그리는 걸 넘어, 데이터 간의 관계를 시각적으로 연결해 줌.
  • 실시간 업데이트: 엑셀 파일의 내용이 바뀌면 '새로고침' 버튼 하나로 모든 그래프가 최신 상태로 업데이트됨.

📊 쿼리(Query) 화면 vs 메인(Main) 화면

  • 쿼리창 (데이터 손질): 원본 데이터(CSV, Excel 등)는 지저분한 경우가 많으므로, 불필요한 행을 지우고, 형식을 바꾸고, 여러 파일을 합치는 '가공 작업'에만 집중하는 공간임. 실제 원본 파일(CSV)은 변하지 않음.
  • 메인창 (시각화): 손질이 끝난 데이터로 보고서를 만드는 '전시 공간'. 데이터 구조가 이미 깔끔하게 정리되어 있으므로, 사용자는 분석에만 몰두할 수 있음.

📊 DAX (Data Analysis Expressions)

1. 기본 정의 및 성격

  • 데이터 모델링 전용 언어: Microsoft Power BI, Excel, Analysis Services에서 데이터를 계산하고 분석하기 위해 설계된 수식 언어.
  • 함수 기반의 구조: 엑셀 수식과 유사한 함수 형태를 띠고 있으나, 개별 셀이 아닌 데이터 테이블 전체를 다루는 데 특화됨.
  • 고급 분석의 필수 도구: 단순한 합계를 넘어 '전년 대비 성장률', '점유율' 등 복잡한 비즈니스 로직 구현에 사용.

2. 프로젝트 내 주요 활용 사례

  • 세대수 합계: SUM 함수를 활용하여 행정동별 세대 데이터 총합 산출.
  • 1인 세대 비중: DIVIDE 함수를 사용하여 전체 세대수 대비 1인 세대수의 비율 계산.
  • 조건부 데이터 추출: 특정 연도나 특정 연령대(예: 30대 여성)만의 이동 패턴 데이터 필터링 및 계산.
