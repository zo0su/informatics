[4차시] 암호화와 데이터 보호

1. 앨런 튜링(Alan Mathison Turing)

앨런 튜링(Alan Turing)은 '컴퓨터 과학의 아버지'이자 '인공지능의 선구자'로 불리는 인물

1. 현대 컴퓨터의 이론적 기초: '튜링 기계'

  • 내용: 1936년 논문을 통해 '튜링 기계(Turing Machine)'라는 가상의 계산 모델을 제안했습니다.
  • 의미: 복잡한 계산을 단순한 단계로 나누어 처리하는 '알고리즘'의 개념을 수학적으로 증명함. 이는 오늘날 우리가 사용하는 모든 프로그램 내장 방식 컴퓨터의 설계 원리가 됨.

2. 2차 세계대전의 영웅: 에니그마 암호 해독

  • 내용: 독일군의 난공불락 암호기인 '에니그마(Enigma)'를 해독하기 위해 전기 기계식 암호 해독기인 '봄베(Bombe)'를 설계함.
  • 의미: 무한에 가까운 암호 조합을 기계적인 연산으로 빠르게 풀어냄으로써 전쟁을 약 2년 단축하고 1,400만 명 이상의 목숨을 구한 것으로 평가받음. 영화 <이미테이션 게임>의 주요 소재이기도 함.

3. 인공지능(AI)의 시초: '튜링 테스트'

  • 내용: 1950년 논문에서 "기계가 생각할 수 있는가?"라는 질문을 던지며 '모방 게임(Imitation Game)', 즉 '튜링 테스트'를 제안함.
  • 의미: 기계가 인간과 구별할 수 없을 정도로 자연스럽게 대화할 수 있다면 지능을 가졌다고 볼 수 있다는 기준을 세움. 이는 오늘날 인공지능 연구의 철학적·이론적 출발점이 됨.

4. 인류 최초의 실용 컴퓨터 설계 기여

  • 내용: 전쟁 후 영국 국립물리학연구소(NPL)에서 자동 계산 엔진(ACE)을 설계하고, 맨체스터 대학교에서 초기 컴퓨터인 '맨체스터 마크 1'의 소프트웨어 개발에 참여함.
  • 의미: 이론에만 머물지 않고 실제 작동하는 초기 컴퓨터 시스템을 구축하는 데 실질적인 공헌을 함.

2. 데이터 암호화 기법_SSL 인증서

SSL(Secure Sockets Layer) 인증서의 핵심 역할

  • 데이터 암호화: 사용자의 브라우저와 웹 서버 사이의 데이터를 암호화다. 설령 중간에 누군가 데이터를 가로채더라도 내용을 읽을 수 없게 만듦.
  • 서버 신원 확인: 접속한 사이트가 가짜(피싱 사이트)가 아닌 진짜임을 증명함.
  • 무결성 보장: 전송되는 데이터가 중간에 위조되거나 변조되지 않았음을 확인함.

SSL 적용 여부 확인법 (HTTP vs HTTPS)

SSL 인증서가 설치된 사이트는 주소창에서 바로 확인할 수 있음.

3. 전치형 암호 기법이란?

  • 전치형 암호(Transposition Cipher)는 평문에 있는 문자들의 종류는 그대로 유지하되, 그 순서(위치)만 바꾸는 암호화 기법
  • 비유하자면, 단어의 철자들을 무작위로 섞는 '애너그램(Anagram)'과 비슷함.
  • 예를 들어 "HELLO"를 "LLEHO"로 바꾸는 식임.
  • 글자 자체가 다른 글자로 바뀌는 '대치형 암호(Substitution Cipher)'와는 확실히 구분됨.

4. 대치형 암호 기법이란?

  • 대치형 암호(Substitution Cipher)는 평문의 각 문자를 정해진 규칙에 따라 다른 문자, 숫자 또는 기호로 바꾸는 방식
  • 전치형 암호가 '순서'를 바꾼다면, 대치형 암호는 '알파벳 그 자체'를 갈아끼우는 것이 핵심
분류기법 명칭작동 원리 및 특징
단일 문자시저 암호 (Caesar)알파벳을 일정한 거리만큼 밀어서 대치합니다. (예: 3칸 이동 시 A to D)
(Mono-alphabetic)단일 치환 암호알파벳 26자를 무작위로 1:1 매칭시킨 표를 만들어 사용함.
다중 문자비즈네르 (Vigenère)키워드(Key)를 반복 사용하여 각 글자마다 서로 다른 이동 거리를 적용함.
(Poly-alphabetic)플레이페어 (Playfair)5x5 행렬을 만들어 두 글자씩 쌍으로 묶어 대치함.
  • 군대의 훈련 상황이나 야전에서 암호 장비(비화기)가 없을 때, 혹은 수동으로 암호를 소통할 때 사용하는 방식은 바로 ‘단일 치환 암호(Simple Substitution)'의 일종인 음어표(Code Table) 방식임.
  • 군대에서 흔히 "암호 조립한다"라고 표현하는 그 과정이 바로 이 방식에 해당함.
